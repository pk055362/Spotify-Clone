# Spotify Clone 🎵

A modern Spotify-inspired music streaming web application that replicates the core functionality and user interface of Spotify. The project focuses on creating an immersive music player experience with responsive design, interactive controls, and seamless user experience.

Built using modern frontend and backend technologies to simulate a real-world music streaming platform.

---

## ✨ Features

- 🎶 Spotify-inspired user interface
- ▶️ Music player with play/pause controls
- ⏭️ Next and previous track functionality
- 🔊 Volume control system
- 📱 Fully responsive design
- 🎧 Dynamic playlist display
- 🖼️ Album and song cover integration
- ⚡ Interactive and smooth UI experience
- 🎵 Real-time music playback handling

## 🚀 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/pk055362/Spotify-Clone.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd Spotify-Clone
```

### 3️⃣ Install Dependencies

```bash
npm install
```

---

## ▶️ Run the Application

```bash
npm start
```

The application will run locally on:

```bash
http://localhost:3000
```
